This project is a designed to help Business owners, Tutors, Clubs, etc. to receive and manage their form data conveniently through Google Sheets. It's an efficient solution with unlimited usage within the Google Sheets free limits.

## Key Features

- **Data visualization**: Offers a summary page with all selections before final submission, promoting informed choices.
![summary step](/projects/form/mobile-image-2_hfhc0x.webp)
- **Automated data storage**: Sends collected data directly to Google Sheets for easy access and organization.
[![Products sheets](/projects/form/multi-step-form-sheets.webp)](https://docs.google.com/spreadsheets/d/1nY3yq3fNXGjKXSacbiURAjWubsdGV_kh8b5pvzFrbek/edit?usp=sharing)

[![Store functions](/projects/form/multi-step-form.gif)](https://multi-steps-form-flame.vercel.app/)
_(Live preview 'version Feb 18, 2024')_

## Technologies Used

The project is built using technologies like:

- **[Next.js 13](https://beta.nextjs.org/docs)**:  React framework
- **MDX**: A format that lets you write JSX embedded inside markdown documents.
- **[TailwindCSS](https://tailwindcss.com/)**: For styles
- **[Framer Motion](https://www.framer.com/motion/)**: For animations
- **[shadcn/ui](https://ui.shadcn.com/)**: UI components :rocket:
- **[googleapis](https://www.npmjs.com/package/googleapis)**: For authorization and authentication
