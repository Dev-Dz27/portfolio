This project is a straightforward online store designed to help store owners manage their products and receive orders conveniently through Google Sheets. It's an efficient solution that allows the owners to list their products and handle unlimited orders within the Google Sheets' free limits.

## Key Features

- **Product Listing**: Easily add and manage products within the store.
![Products sheets](/projects/sheetstore/googlesheet-products.webp)
- **Order Management**: Receive and organize orders efficiently through Google Sheets.
![Products sheets](/projects/sheetstore/googlesheet-orders.webp)
- **Personalization**: Store owners can personalize their store by adding their location and social media information.
![Products sheets](/projects/sheetstore/googlesheet-info.webp)
- **Mobile Integration**: Includes a manifest file allowing users to add the store as an app on their phones for seamless integration into their daily lives.

[![Store functions](/projects/sheetstore/sheetstore.gif)](https://sheetstore.vercel.app/)
_(Live preview 'version Dec 24, 2023')_

## Technologies Used

The project is built using technologies like:

- **Next.js**: A powerful React framework for building fast and efficient web applications.
- **MDX**: A format that lets you write JSX embedded inside markdown documents.
- **Tailwind CSS**: A utility-first CSS framework for creating custom and responsive designs easily.
- **Framer Motion**: A library for creating animations in React applications, making the store visually engaging.
- **Papaparse**: A CSV parsing and processing library used for handling data from Google Sheets.
- **Cypress**: A testing framework ensuring the store functions reliably across different scenarios.
- **Googleapis**: Google's API library used for integrating Google Sheets with the store.
- **Radix UI**: Components like dialogs, labels, and toggles to enhance user interaction and experience.
